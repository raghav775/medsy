Frequently asked questions

The current behavior at a glance.

Do I need to log in before using Pharmacy Finder?

No. The Pharmacy Finder is intentionally public so emergency searches can start immediately.

Can I type medicines instead of uploading a prescription?

Yes. The finder supports both upload-based OCR and manual text entry.

What should I still confirm with the pharmacy?

Confirm stock, exact dosage, timing, pricing, and any transfer or refill details before you go.
